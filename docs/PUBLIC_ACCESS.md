# Public source and documentation

The public snapshot is published at
[unaivicente/sports-codex-public](https://github.com/unaivicente/sports-codex-public).
Read the [documentation index](https://github.com/unaivicente/sports-codex-public/blob/main/docs/README.md)
or [project overview](https://github.com/unaivicente/sports-codex-public#readme)
without signing in.

## Publication model

The working repository was detected as `unaivicente/sports-codex`. The public
repository is a reviewed source snapshot with new Git history. The original
repository remains private and retains its history; its historical environment
files are not part of this publication.

The public snapshot includes tracked application/package source, tests,
dependency lockfile and documentation. It excludes original Git history,
local environment files, media, databases, model outputs, installed dependencies
and macOS directory metadata. Snapshot updates are explicit; no automatic
synchronization is configured between repositories.

```sh
git clone https://github.com/unaivicente/sports-codex-public.git
cd sports-codex-public
```

Follow [getting started](GETTING_STARTED.md) to run it locally.

## Verification

Publication is checked using repository visibility metadata and anonymous
requests to the public repository, raw README and documentation index. Public
access to source does not deploy a live web app, API, database or model service.
The Python APIs remain local development servers, as documented in
[architecture](ARCHITECTURE.md).
